DIGI-FUZE

A retro console where any two cartridges become a new game. An AI model reads both games' code and writes a fusion: first a playable level 1, then the full game if you want it, shaped by your notes.

Remixing uses your own Anthropic or OpenRouter API key. It stays in this browser and goes only to that provider. Your remixes are saved in this browser too: use Export to keep or share them.

It's also a benchmark: Results compares models on time, tokens, cost and how fun their games are.
